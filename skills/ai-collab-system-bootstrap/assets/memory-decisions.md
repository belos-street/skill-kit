# 决策记录（Decisions Log）

> 本文件记录项目中**已敲定、需长期遵守**的技术与流程决策，供真人与 LLM 共读。
> LLM 在承接任务前应阅读本文件，避免重复讨论或推翻既有结论；做出新的重要决策时应追加到本文件。
>
> 记录格式：每条决策包含「结论」「背景/理由」「日期」。最新决策追加在末尾（只追加不覆盖，编号递增）。

- **理由**：`doc/` 面向真人阅读为主，职责与 `.agents/`（面向 AI）不同，分开存放更清晰。

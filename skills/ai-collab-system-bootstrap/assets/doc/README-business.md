# 业务域知识（doc/business/）

> 存放各业务模块的「项目事实」：组件地图、枚举速查、API 落点、已知坑。
> 与 `doc/api/`（接口事实层）、`doc/architecture/`（技术架构与开发指南）区分：本目录按业务域组织，随业务演进持续补充。

## 目录约定

- 按域一个文档（或子目录），如 `project-task.md`、`rule.md`；
- 命名 `kebab-case`，与源码业务目录对齐；
- 事故复盘优先补进对应域文档的「已知坑」；
- 模板见 `doc/templates/business-domain.md`。

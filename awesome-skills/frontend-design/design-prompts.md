# design/prompts

- **来源**：[designprompts.dev](https://www.designprompts.dev/)
- **用途**：设计风格提示词库（AI-Powered Design Style Explorer），把现成 prompt 丢进任意 AI 助手即可产出风格一致的界面
- **适用场景**：需要快速定调设计风格时（探索期、原型期）；按 Mode / Type（Serif / SansSerif / Mono）筛选，覆盖 30+ 风格：Monochrome、Bauhaus、Modern Dark、Newsprint、SaaS、Luxury、Terminal、Swiss Minimalist、Neo Brutalism、Cyberpunk、Vaporwave 等
- **内容形式**：每种风格一条完整 prompt，描述设计系统（配色、字体、版式、气质），例如 Monochrome 是纯黑白编辑风、超大衬线标题、几何精确布局
- **与本项目关系**：`skills/ui-templates` 即参考该站而来

- **收录状态**：观望（已间接参考进 `skills/ui-templates`）

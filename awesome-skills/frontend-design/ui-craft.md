# UI Craft

- **来源**：[官网](https://skills.smoothui.dev/) · [GitHub](https://github.com/educlopez/ui-craft)
- **用途**：教 AI coding agent 产出有设计质感的 UI，拒绝"AI 味"输出（紫青渐变、弹跳动画、玻璃拟态等 15 种典型 slop 模式）
- **适用场景**：用 agent 生成前端页面、组件、dashboard 时的质量把关；非模板库/组件库，而是设计工程知识（23 个领域的规则集：版式、排版、色彩、动效、无障碍、仪表盘、表单、数据可视化等）
- **工作模式**：Build（一次性生成）/ Animate（动效）/ Review（审计）/ Polish（精修）；另提供 15 个 `/ui-craft:*` slash 命令（如 `audit`、`critique`、`polish`、`typeset`）
- **可调参数**：`CRAFT_LEVEL`（精细度）、`MOTION_INTENSITY`（动效强度）、`VISUAL_DENSITY`（信息密度），影响行为而非仅措辞
- **兼容性**：Claude Code / Codex / Cursor / Gemini / OpenCode，各 agent 有预置镜像
- **安装**：`npx skills add educlopez/ui-craft`
